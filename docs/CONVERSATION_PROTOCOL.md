# Codex Conversation Protocol

## Start every implementation task with

```text
Repository: game-project
Worktree and branch: feat/WB-012-asset-library
Requirement: WB-012
Outcome: Asset library MVP with upload metadata, approval status, and filtering.
Acceptance criteria: [list]
Out of scope: Game client and deployment.
```

## Conversation types

- **Architecture** — durable design decisions; update an ADR.
- **Feature delivery** — one scoped branch and outcome; archive after merge.
- **Bug fix** — one root cause or closely coupled defect set; archive after merge.
- **Review / release** — assess a known diff or a release candidate; retain with release notes.

Chat is not the system of record. Persist decisions, requirement IDs, verification results, and release notes in the repository or workbench.
